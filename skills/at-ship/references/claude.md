# Under a Claude Code lead

- Invoke as `/at-ship <goal> [--convergence …] [--team]`. Claude Code exports `CLAUDE_PLUGIN_ROOT`, which the locator accepts first when it passes the Triforge-root test.
- A sub-agent is the Agent tool: `learnings-researcher`, `plan-checker`, `security-sentinel`, `performance-oracle`, `code-simplicity-reviewer`, `findings-synthesizer`, `test-gap-analyzer`, `integration-verifier` and `team-lead` are the shipped agent definitions of those names. Pin `model` and `effort` on every spawn, launch parallel reviewers in a single message, wait for each one, and record a sub-agent that returns nothing as a failed sub-task. `plan-checker`, `security-sentinel` and `findings-synthesizer` are never downgraded.
- Agent-team mode (`--team`, or 5+ interdependent tasks) is Claude agent teams coordinated by `team-lead`.
- The `/goal` line: a skill cannot invoke `/goal` itself. The user types it, or it is the leading line of a `claude -p` prompt, which is exactly how `$ROOT/scripts/coordinate.sh` composes each iteration's prompt. Typing it makes Claude Code hard-gate the session natively; headless gating is model-behavior-dependent (probe CC-03 passed 1 of 3 runs in the 2026-09 cycle, D-030), so the checklist is a best-effort assist and the `ops/.sprint-complete` sentinel stays the authoritative completion signal.
