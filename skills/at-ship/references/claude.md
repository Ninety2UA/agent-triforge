# Under a Claude Code lead

- Invoke as `/at-ship <goal> [--convergence …] [--team]`. Claude Code exports `CLAUDE_PLUGIN_ROOT`, which the locator accepts first when it passes the Triforge-root test.
- Personas start detached through `persona_spawn` in the Bash tool, not the Agent tool, parallel ones in one block; run the wait block with the Bash tool at `timeout: 600000`, never `run_in_background`: `persona_wait` returns inside the registry's 600 s `wait_budget_s`, with 75 while personas still run, so you rerun it. One that fails or writes nothing is a failed sub-task. Agent-team mode (5 or more tasks, or `--team`) is the one Agent-tool spawn: the `team-lead` persona under Claude's agent-teams capability, as the `at-build` skill describes (its tools are not enforced there).
- The `/goal` line: a skill cannot invoke `/goal` itself. The user types it, or it is the leading line of a `claude -p` prompt, which is exactly how `$ROOT/scripts/coordinate.sh` composes each iteration's prompt. `/goal` is an assist (CC-03 went 0 of 3 on 2.1.318) and `ops/.sprint-complete` plus `coordinate.sh` decide completion.
