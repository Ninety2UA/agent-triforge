# Under a Claude Code lead

- Invoke as `/at-coordinate <goal>`. Claude Code exports `CLAUDE_PLUGIN_ROOT`, which the locator accepts first when it passes the Triforge-root test.
- Personas run through `dispatch_persona` in the Bash tool, not the Agent tool: start parallel ones in the background of one call and wait for each; one that fails or writes nothing is a failed sub-task. Agent-team mode (5 or more tasks, or `--team`) is the one Agent-tool spawn: the `team-lead` persona under Claude's agent-teams capability, as the `at-build` skill describes (its tools are not enforced there).
- The `/goal` line: a skill cannot invoke `/goal` itself. The user types it, or it is the leading line of a `claude -p` prompt, which is exactly how `$ROOT/scripts/coordinate.sh` composes its per-iteration prompt. Typing it makes Claude Code hard-gate the session natively; headless gating is model-behavior-dependent (probe CC-03 passed 1 of 3 runs in the 2026-09 cycle, D-030), so the checklist is a best-effort assist and the `ops/.sprint-complete` sentinel stays the authoritative completion signal the coordinator reads.
