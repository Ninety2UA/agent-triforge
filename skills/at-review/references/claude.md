# Under a Claude Code lead

- Invoke as `/at-review [flags]`. Claude Code exports `CLAUDE_PLUGIN_ROOT`, which the locator accepts first when it passes the Triforge-root test.
- The specialist reviewers are Claude sub-agents, the Agent tool, using the shipped agent definitions of those names: `--full` or `--security` → `security-sentinel`; `--full` or `--perf` → `performance-oracle`; `--full` or `--simple` → `code-simplicity-reviewer`; `--full` also → `convention-enforcer` and `architecture-strategist`. Launch all applicable sub-agents in a SINGLE message for maximum parallelism, pin `model` and `effort` on each, and wait for all reviewers to complete before Phase 4. `security-sentinel` and `findings-synthesizer` are never downgraded.
- rc 40 from `dispatch_role`: that role resolved to the Claude lane (its default CLI is absent, or the roster pins `cli = "claude"`). Spawn a native Claude sub-agent (the Agent tool) for that reviewer against the `[R]` scope, `architecture-strategist` for the analyst lane and a logic + security review for the reviewer lane, writing findings to `ops/REVIEW_ANTIGRAVITY.md` / `ops/REVIEW_CODEX.md` respectively, so `findings-synthesizer` sees them alongside the other lanes.
- `learnings-researcher` (when the gate says spawn) and `findings-synthesizer` are Agent-tool sub-agents as well.
